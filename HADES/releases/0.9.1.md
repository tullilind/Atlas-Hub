# HADES 0.9.1

Versão que inaugura o atualizador oficial do HADES.

- Fonte oficial de atualização: `Atlas-Hub/HADES/manifests/stable.json`.
- Detecção automática de Windows, Debian/Ubuntu e arquitetura.
- Download temporário e verificação SHA-256 obrigatória.
- A atualização só é marcada como concluída quando a nova versão realmente inicia.
- Registro de instalação canônica para reduzir abertura acidental de executáveis antigos.
- Preparação de instalador Windows com Inno Setup.
- Preparação de pacote Debian `.deb`.
- Dados persistentes continuam fora da pasta de instalação.
- Termos de instalação e licença da ATLAS TECNOLOGIA.

Os artefatos binários serão anexados à GitHub Release `hades-v0.9.1`. Até que isso ocorra, o manifesto não anuncia pacote para download.
